# Simple X-Ray 

A simple and lightweight X-Ray mod for Minecraft Java Edition.

## Features
- Toggle X-Ray with F8.
- See ores through blocks.
- Different colors for different ores.
- Automatic nearby ore detection.

## Ore Colors

| Ore | Color |
|---|---|
| Diamond | Blue |
| Gold | Yellow |
| Emerald | Green |
| Redstone | Red |
| Lapis | Dark Blue |
| Iron | White |
| Copper | Orange |
| Coal | Gray |

## Requirements
- Minecraft 1.20.1
- Fabric Loader
- Fabric API
- Java 17

## Installation
1. Install Fabric for Minecraft 1.20.1.
2. Install Fabric API.
3. Download Simple X-Ray from Releases.
4. Put the JAR file into your mods folder.
5. Press F8 in-game.
